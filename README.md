# TODO State Management

A modern Todo application built with React, Vite, and Redux Toolkit, featuring a space-inspired user interface and centralized state management for efficient task handling.

## Overview

This project demonstrates how to manage application state using Redux Toolkit in a React application. Users can create, update, complete, and delete tasks while maintaining a predictable and scalable state architecture.

## Features

- Add new tasks
- Edit existing tasks
- Mark tasks as completed
- Delete tasks
- Centralized state management with Redux Toolkit
- Responsive user interface
- Space-themed design
- Fast development environment powered by Vite

## Tech Stack

- React
- Redux Toolkit
- React Redux
- Vite
- JavaScript
- CSS

## Installation

Clone the repository:

```bash
git clone https://github.com/githarsh7/TODO-STATEMANAGEMENT.git
```

Navigate to the project directory:

```bash
cd TODO-STATEMANAGEMENT
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Redux State Management

The application uses Redux Toolkit to simplify state management and reduce boilerplate code.

Core concepts implemented:

- Store configuration
- Slices and reducers
- Actions
- State updates using Immer
- React Redux integration with hooks

## Learning Objectives

This project is designed to demonstrate:

- Component-to-store communication
- Scalable project architecture
